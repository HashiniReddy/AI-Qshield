# 🛡️ AI-QShield

## Explainable Multi-Layer QR Quishing Detection & Attack Fingerprinting System

AI-QShield is a cybersecurity system designed to detect and analyze
QR-code-based phishing attacks, commonly known as Quishing.

## Core Idea

Instead of relying on a machine-learning classifier, AI-QShield
combines multiple security-intelligence and behavioral-analysis
techniques to determine the risk of QR-linked content.
